## Install

Requires the [pi coding agent](https://github.com/earendil-works/pi) — install it first: `npm install -g @earendil-works/pi-coding-agent`.

```sh
pi install npm:@arhen/pi-core-tps-stats
```

Live token-per-second stats for the active model. Status bar shows median streaming t/s + average TTFT; `/tps-stats` shows full stats (samples, avg/median/min/max, effective t/s, TTFT). Stats reset on model change.
