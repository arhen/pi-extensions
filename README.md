# @arhen/add-pi-wafer

[![npm version](https://img.shields.io/npm/v/@arhen%2Fadd-pi-wafer?color=cb3837&logo=npm)](https://www.npmjs.com/package/@arhen/add-pi-wafer)
[![license](https://img.shields.io/badge/license-MIT-blue.svg)](./LICENSE)

Wafer Serverless provider for pi. Live model catalog, Zero Data Retention toggle, usage stats.

- Login: `/login` → "Wafer Serverless" → API key (or `WAFER_API_KEY`)
- Commands: `/wafer` status · `/wafer zdr [on|off]` · `/wafer refresh` · `/wafer models` · `/wafer usage` · `/wafer hide`

## Install

```sh
pi install npm:@arhen/add-pi-wafer
```
